## 1. 设计目标

本系统要解决的是“玩家如何发现世界规律”，而不是“游戏引擎如何计算碰撞、重力和动量”。

游戏世界的普通存在逻辑仍由常规引擎处理：角色站在地上、石头会下落、箭矢有弹道、物体有碰撞盒。这些是基础物理。

科研探索系统需要的是同一套世界规律在更高阶变量上的表现：它比重力、动量、碰撞更深，但不深入到原子、量子或宇宙本质规律。它应当更像“逻辑层物理”或“中尺度现象学规律”：

- 玩家可以通过设备观察它。
- 玩家可以通过材料、环境、结构、历史和状态改变它。
- 玩家可以基于它制造工具、建筑、武器、药剂、交通系统和情报系统。
- 它和真实世界规律有抽象关系，但允许在幻想世界中变体化。
- 它不要求引擎模拟每个原子，只需要在常态区间使用快速近似，在异常区间处理对象级、区域级、事件级变量。

核心要求：

```text
真实世界抽象 -> 游戏世界变体 -> 玩家可观察现象 -> 可制造设备 -> 新规律线索
```

## 2. 设计边界

### 2.1 不是引擎物理

本系统不接管基础运动模拟。它不负责：

- 角色移动。
- 普通刚体碰撞。
- 重力下落。
- 基础投射物轨迹。
- 传统伤害判定。

这些仍由引擎与战斗系统处理。

这一分工不要求特殊材料仍表现为普通材料。悬浮、局部重力变化和新型运输可以通过引擎支持的受力与约束接口结算。早期环境缺少可获取的异常材料，与后期设备改变运动方式可以同时成立。

### 2.2 不是原子尺度模拟

本系统也不模拟：

- 原子排列。
- 分子反应路径。
- 量子态坍缩。
- 基本粒子。
- 从微观粒子层推导宇宙常数。

玩家不会拿显微镜一颗一颗看原子。系统只处理设计师定义的对象级属性。

表层经验参数仍可由有限的隐藏状态和深层规则决定，玩家起初可能把它们当作常数；这不要求引入微观模拟。参数层次与平衡原则见元设计第 7.6 节。

### 2.3 是逻辑层物理

每个可交互对象、区域、设备、材料和生命体，都可以拥有一组抽象物理属性：

```text
ObjectState = {
  matter_class,
  essence_signature,
  life_coherence,
  soul_trace,
  temperature_band,
  stress_level,
  purity,
  geometry_profile,
  boundary_state,
  resonance_phase,
  memory_depth,
  information_fidelity,
  provenance_history
}
```

这些属性不需要全部显示给玩家，也不需要全部实时模拟。它们在采集、制造、鉴定、实验、战斗、仪式、环境事件和世界结算中被读取或改变。

## 3. 核心模型

每条玩家可交互物理规律可以写成：

```text
Phenomenon = Law(ObjectState, DeviceState, RegionState, Operation, History)
```

玩家不能直接看到 `Law`。玩家先看到的是 `Phenomenon`，也就是现象：

- 某种矿物在黄昏时变轻。
- 两个同源金属杯会在远距离同时震动。
- 某些战场遗物无法被普通火焰熔化。
- 某段道路上运输队的钟表总是慢三分钟。
- 某种草药被月光照过后药性反转。

然后玩家通过设备和实验把现象变成假说：

```text
Observation -> Pattern -> Hypothesis -> Reproducible Experiment -> Law Fragment -> Application
```

完整规律不是一次发现的。玩家可以先发现规律的一角，制造设备，再用设备观察另一条规律的表象。

能力进步让发现变得可行：设备可以帮助玩家抵达深层地质、取得新材料、维持实验条件或提高测量精度。规律始终按实际条件生效，不检查个人是否先完成某个科技节点。取得样品、观察现象、解释规律和稳定量产应分开记录。

## 4. 规律交织模型

本系统的重点不是孤立规律，而是规律之间互相作为观测入口。

抽象结构：

```text
gA -> dA -> observes(pC_from_angle_A)
gB -> dB -> observes(pC_from_angle_B)
pC_from_angle_A + pC_from_angle_B + experiment -> understand(gC)
gC -> dC1 / dC2 -> observes(gD, gE...)
```

其中：

- `gA`：已发现或部分发现的规律。
- `dA`：基于 `gA` 制造的设备。
- `pC_from_angle_A`：规律 C 从 A 路径观察到的表象。
- `gC`：被统一解释后的更深规律。
- `dC1 / dC2`：基于 C 形成的新设备族。

这能让科研不是线性科技树，而是一个逐步拼合的知识图谱。

## 5. 可交互规律的设计格式

每条规律按以下格式设计：

```text
Law {
  id
  player_facing_name
  hidden_name
  real_world_abstraction
  game_world_variant
  required_scale
  primary_variables
  effective_parameters
  deeper_parameter_dependencies
  capability_requirements
  observable_phenomena
  early_devices
  mature_devices
  applications
  countermeasures
  scenario_tradeoffs
  bridges_to_other_laws
}
```

面向玩家时，不显示 `hidden_name`。玩家只看到现象、命名权、假说和已验证结论。

`effective_parameters` 定义表层参数及范围；`deeper_parameter_dependencies` 记录存在的深层依赖，没有依赖时可为空。`capability_requirements` 描述抵达、采样、加工和观测的实际条件。`scenario_tradeoffs` 定义路线在主要场景中的优势、代价及可调节参数；深层增效技术也须纳入比较。

## 6. 第一批基础规律候选

这些规律不是终局技能，而是构成终局技能的中层物理。它们应该像真实世界中的热、压强、共振、催化、记忆效应、边界条件那样，被许多系统共同使用。

### 6.1 同调耦合

隐藏名：`Coherent Coupling`

真实世界抽象：共振、同步、波耦合、锁相。

游戏世界变体：具有相近来源、材料结构或精粹签名的对象，会在特定状态下共享微弱响应。

主要变量：

- `resonance_phase`
- `essence_signature`
- `geometry_profile`
- `provenance_history`
- `distance_damping`

可观察现象：

- 两个同源材料打造的钟在远距离出现微弱同步误差。
- 同一矿脉出产的晶体在特定音乐、咒文或机械振动下同时发亮。
- 某些武器在靠近旧战场时产生不正常鸣响。

早期设备：

- 共鸣叉：检测材料是否同源。
- 谐振灯：显示区域内微弱同步波动。
- 相位墨水：在纸面上记录物体响应曲线。

成熟应用：

- 远距报警。
- 低带宽同步通信。
- 锚点预同步。
- 精密制造校准。

反制方式：

- 去相干噪声。
- 异源材料包覆。
- 几何扰动。
- 伪造相位签名。

桥接规律：

- 可以从侧面观察“连续性印记”。
- 可以参与空间锚点、远距传能和延迟传送的前置研究。

### 6.2 滞后记忆

隐藏名：`Hysteretic Memory`

真实世界抽象：磁滞、材料疲劳、塑性变形、热历史、形状记忆合金。

游戏世界变体：物体不只拥有当前状态，也保留部分经历痕迹。过去的火焰、压力、战斗、誓言、死亡或仪式，会改变它之后对环境的响应。

主要变量：

- `memory_depth`
- `stress_level`
- `temperature_band`
- `soul_trace`
- `operation_history`

可观察现象：

- 同样的铁矿，经历过战场火焰后更容易承载攻击性附魔。
- 被多次修复的盾牌不是单纯变旧，而是在特定攻击下产生预判性裂纹。
- 长期运送药品的木箱对生命精粹更稳定。

早期设备：

- 应力纹镜：看见材料内部的历史裂纹。
- 退火炉：抹除或重写一部分材料记忆。
- 记忆锤：通过重复冲击给金属写入工艺倾向。

成熟应用：

- 可训练装备。
- 自适应护甲。
- 战场遗物锻造。
- 历史型建筑强化。

反制方式：

- 过载退火。
- 历史污染。
- 伪造战场记忆。
- 记忆洗白。

桥接规律：

- 与“灵魂残响”结合后产生传奇装备。
- 与“信息保真”结合后产生可复制工艺模板。
- 可从另一个侧面观察“连续性印记”。

### 6.3 势差流

隐藏名：`Gradient Flow`

真实世界抽象：热从高温流向低温，水从高处流向低处，电势差驱动电流，化学势驱动扩散。

游戏世界变体：物质、精粹、生命力和灵魂痕迹都存在“势差”。玩家可以建立通道，让某类本质资产沿势差流动。

主要变量：

- `potential_difference`
- `channel_quality`
- `boundary_state`
- `medium_resistance`
- `flow_contamination`

可观察现象：

- 某些山谷会自然吸引生命类资源繁殖。
- 战后地区的灵魂痕迹向古老祭坛聚集。
- 法力矿附近的普通金属会逐渐带上精粹签名。

早期设备：

- 势差罗盘：显示某类本质资产的流向。
- 导流槽：让精粹或生命力沿固定路径迁移。
- 隔绝瓶：阻断微弱泄漏。

成熟应用：

- 资源培育。
- 区域修复。
- 能源网络。
- 战场污染控制。

反制方式：

- 截流。
- 反向泵。
- 污染源投放。
- 边界打孔。

桥接规律：

- 与“边界透性”共同解释许多区域异常。
- 是炼金、生态恢复、亡灵灾害和资源迁移的基础。

### 6.4 边界透性

隐藏名：`Boundary Permeability`

真实世界抽象：膜、阀门、绝缘体、屏蔽、催化表面、相界面。

游戏世界变体：两个对象、区域或本质资产之间能否发生作用，取决于边界是否允许对应的“影响”通过。

主要变量：

- `boundary_state`
- `surface_pattern`
- `purity`
- `ritual_mark`
- `pressure_delta`

可观察现象：

- 同一瓶药水装在不同材质容器中，药性衰减速度完全不同。
- 某些墙壁挡不住声音，却能挡住精粹流。
- 一些古门不是被锁住，而是拒绝特定历史或灵魂痕迹通过。

早期设备：

- 透性试纸：测试容器对四大本质资产的泄漏率。
- 封界蜡：临时降低对象边界透性。
- 刻界刀：在表面刻出可控通道。

成熟应用：

- 高级储存容器。
- 防护结界。
- 精粹阀门。
- 资源提纯与污染隔离。

反制方式：

- 边界腐蚀。
- 表面刮除。
- 压差破界。
- 伪装通行签名。

桥接规律：

- 与“势差流”共同构成大部分资源工程。
- 与“同调耦合”结合后产生锚点屏蔽技术。

### 6.5 催化转化

隐藏名：`Catalytic Transduction`

真实世界抽象：催化剂、酶、反应路径、相变诱导。

游戏世界变体：某些材料、仪式、结构或生命体不会直接变成产物，但能降低一类转化的门槛，使本质资产从一种表达形式转为另一种。

主要变量：

- `catalyst_signature`
- `input_ratio`
- `ambient_condition`
- `purity`
- `conversion_loss`

可观察现象：

- 某种普通矿粉加入药剂后不提供药效，却让草药药性翻倍。
- 某些旧战场灰烬能让灵魂类材料更容易附着在武器上。
- 海克斯装置在祖安污染空气中效率异常提高。

早期设备：

- 反应盘：测试小规模转化路径。
- 催化谱灯：显示催化剂适合影响哪类本质资产。
- 损耗秤：记录转化损失。

成熟应用：

- 替代配方。
- 稀缺资源绕行。
- 高级炼金。
- 战时快速制造。

反制方式：

- 催化剂污染。
- 抑制剂。
- 错误环境诱导。
- 供应链封锁。

桥接规律：

- 是动态资源生态的核心。
- 可以把资源危机变成新科研路线。
- 与“经济熵”天然相连：转化永远有损耗，损耗本身可以被优化但不能归零。

### 6.6 结构承载

隐藏名：`Load-Bearing Structure`

真实世界抽象：结构强度、临界载荷、尺度效应、工程安全系数。

游戏世界变体：越强的精粹流、生命场、灵魂痕迹或时序异常，需要越稳定的物质结构承载。强能力不能凭空存在，必须依附于建筑、容器、阵列、地形或仪器。

主要变量：

- `load`
- `structure_integrity`
- `geometry_profile`
- `material_class`
- `failure_mode`

可观察现象：

- 小型时间减速容器可行，房间级时间场会撕裂普通墙体。
- 同样的法力核心放进不同几何结构，输出上限差异巨大。
- 战场上被破坏的锚点不是爆炸，而是“失载”后缓慢失配。

早期设备：

- 载荷尺：测量设备可承受的异常强度。
- 稳定框架：提升小型实验安全阈值。
- 失效记录针：记录设备崩溃模式。

成熟应用：

- 战略级装置基座。
- 城市级护盾塔。
- 大型传送锚点。
- 巨构科研设施。

反制方式：

- 结构破坏。
- 共振疲劳。
- 过载诱导。
- 基座地形改变。

桥接规律：

- 把“魔法”落回工程，避免能力无限便携。
- 与建筑、战争工程和资源消耗强绑定。

### 6.7 信息保真

隐藏名：`Informational Fidelity`

真实世界抽象：测量误差、编码、压缩、噪声、蓝图、数字孪生。

游戏世界变体：一个对象的“可被描述程度”会影响复制、修复、传送、鉴定和伪造。信息越完整，越能重构或预测对象行为。

主要变量：

- `information_fidelity`
- `sampling_resolution`
- `noise_level`
- `observer_skill`
- `record_medium`

可观察现象：

- 高级工匠能从一把剑的微小纹路反推出锻造流程。
- 假情报在文字层面完美，但缺少自然奥术水印。
- 传送失败不是因为距离，而是因为目标状态描述不完整。

早期设备：

- 工艺拓印纸：保存对象表面与精粹签名。
- 噪声镜：看见记录中的缺失部分。
- 证伪印章：对情报来源做低级完整性检定。

成熟应用：

- 高级蓝图。
- 逆向工程。
- 远程维护。
- 部分物质重构。
- 情报鉴定。

反制方式：

- 噪声注入。
- 签名伪装。
- 记录介质污染。
- 刻意制造不可测状态。

桥接规律：

- 与“滞后记忆”结合后形成历史可读装备。
- 与“同调耦合”结合后成为远距同步通信基础。
- 与“连续性印记”结合后可发展出更高级传送/复制技术。

### 6.8 连续性印记

隐藏名：`Continuity Imprint`

真实世界抽象：路径依赖、身份连续性、拓扑不变量、对象持久性。

游戏世界变体：世界不只关心一个对象现在是什么，也关心它是否仍被判定为“同一个东西”。修复、分解、传送、复制、重生和继承都会触碰连续性边界。

主要变量：

- `provenance_history`
- `identity_anchor`
- `memory_depth`
- `information_fidelity`
- `soul_trace`

可观察现象：

- 一把多次重铸的剑仍被某些 NPC 认作同一把家族剑。
- 两件复制品属性相同，但只有原物能打开古代誓约门。
- 传送锚点拒绝“身份断裂”的生物组织通过。

早期设备：

- 源流印：记录物品来源链。
- 同一性秤：比较两件对象是否共享连续性。
- 断裂针：检测复制、传送或重铸造成的身份裂缝。

成熟应用：

- 可靠传送。
- 遗产系统。
- 传奇装备继承。
- 复制品合法性鉴定。
- 高阶重生仪式。

反制方式：

- 来源链伪造。
- 身份污染。
- 锚点替换。
- 断裂攻击。

桥接规律：

- 是 `gC` 级别的候选核心规律。
- 可以被“同调耦合”和“滞后记忆”从不同侧面观察。
- 解锁后可通往传送、复制、社会性死亡、遗产继承等大型系统。

### 6.9 生命相容

隐藏名：`Biotic Compatibility`

真实世界抽象：免疫反应、生态位、共生、毒性、组织排异。

游戏世界变体：生命类对象对物质、精粹、灵魂和环境状态有相容性。生物组织不是更复杂的物品，而是一类会主动维持自身边界和连续性的系统。

主要变量：

- `life_coherence`
- `toxicity`
- `essence_signature`
- `boundary_state`
- `stress_level`

可观察现象：

- 同一种药对不同地区居民效果不同。
- 传送无机物容易，传送活体困难。
- 被污染区域不是单纯扣血，而是逐步改变生命相容性。

早期设备：

- 活性试皿：检测药剂对生命 coherence 的影响。
- 共生苗床：培养区域适配型草药。
- 排异针：预测生命体对附魔或义体的排斥。

成熟应用：

- 地区医学。
- 生物装备。
- 活体传送稳定。
- 生态修复。
- 士兵适应性改造。

反制方式：

- 毒性转译。
- 相容性污染。
- 共生链破坏。
- 生命边界干扰。

桥接规律：

- 与“边界透性”共同解释药剂、污染和生态系统。
- 与“连续性印记”共同决定活体传送和重生系统的上限。

### 6.10 灵魂残响

隐藏名：`Soul Echo`

真实世界抽象：历史记忆、文化意义、心理创伤、社会认同、叙事沉淀。

游戏世界变体：强烈意志、死亡、誓言、背叛、荣耀和群体记忆会沉淀为可交互的灵魂痕迹。它不是纯叙事 flavor，而是第四类本质资产【灵魂】的规律基础。

主要变量：

- `soul_trace`
- `collective_attention`
- `emotional_charge`
- `provenance_history`
- `ritual_mark`

可观察现象：

- 大型战役后的土地会出现可采集的誓言、恐惧或复仇残片。
- 一个被全服纪念的角色退场后，其遗物出现独特主动效果。
- 谣言和集体恐慌会改变某些区域的灵魂资产产出。

早期设备：

- 回响铃：检测灵魂痕迹强度。
- 誓约瓶：短期保存某类情绪残响。
- 纪事墨：把事件记录转化为可验证的灵魂载体。

成熟应用：

- 传奇装备。
- 城邦文化增益。
- 高阶 NPC 关系影响。
- 社会性死亡与遗产特性。

反制方式：

- 记忆污染。
- 伪史传播。
- 仪式破坏。
- 遗物亵渎。

桥接规律：

- 与 GDD 的“身份大于装备”“社会性死亡”“符文之地编年史”强绑定。
- 与“连续性印记”共同解释为什么某些名字、头衔和遗产不能被普通复制。

## 7. 三规律交织样例

这是对 `gA -> dA`、`gB -> dB`、共同观察 `gC` 的直接落地。

### 7.1 第一阶段：从同调耦合发现异常

玩家发现 `gA = 同调耦合`。

他们制造 `dA = 谐振灯`。

谐振灯原本用于检测同源材料，但在某些旧战场遗物附近会出现奇怪现象：两个来源不同、材质不同的对象，如果都经历过同一次历史事件，竟然出现微弱同步。

这不是普通同源材料共振。

玩家得到现象：

```text
pC_A = 不同对象因为共享历史而产生同步响应
```

### 7.2 第二阶段：从滞后记忆发现另一侧异常

另一批玩家发现 `gB = 滞后记忆`。

他们制造 `dB = 应力纹镜`。

应力纹镜原本用于读取材料受力历史，但在检测战场遗物时，发现有些裂纹不是由物理冲击造成的，而是由“身份断裂”造成的。比如同一把剑被重铸后，普通结构已恢复，但某些誓约门仍拒绝承认它。

玩家得到现象：

```text
pC_B = 对象经历改变后，世界对它是否仍为同一物的判定会变化
```

### 7.3 第三阶段：统一为连续性印记

当玩家把 `pC_A` 和 `pC_B` 合并，并设计可复现实验：

```text
同源材料同步实验
+ 战场历史污染实验
+ 重铸前后身份门验证
-> gC = 连续性印记
```

他们发现世界存在一种逻辑层规律：对象拥有“连续性印记”。物体、生命体、装备、城市、誓言甚至角色身份，都可能携带连续性。

### 7.4 第四阶段：基于 gC 的新设备

解锁 `gC` 后，可以制造：

- `dC1 = 源流印`：记录物品来源链，用于高端装备、遗产、贸易鉴定。
- `dC2 = 同一性秤`：比较两件对象是否仍被世界判定为同一对象。
- `dC3 = 断裂针`：检测传送、复制、重铸、重生造成的身份裂缝。

这些设备会进一步打开新规律：

```text
dC1 -> 发现灵魂残响的稳定沉淀条件
dC2 -> 发现信息保真不足会破坏连续性
dC3 -> 发现活体传送失败与生命相容有关
```

于是：

```text
gC -> dC1/dC2/dC3 -> gD/gE/gF
```

科研系统自然向更深层展开。

## 8. 与四大本质资产的关系

GDD 第 14 章定义了四大本质资产：【物质 Matter】、【精粹 Essence】、【生命 Life】、【灵魂 Soul】。

玩家可交互物理规律不是第五类资产，而是解释四类资产如何转化、约束、储存、泄漏、污染和组合的规则层。

对应关系：

| 本质资产 | 最相关规律 | 主要玩法 |
| --- | --- | --- |
| 物质 | 滞后记忆、结构承载、边界透性 | 锻造、建筑、耐久、装备进化 |
| 精粹 | 同调耦合、势差流、催化转化 | 附魔、能源、装置、法术工程 |
| 生命 | 生命相容、边界透性、势差流 | 药剂、生态、医学、活体稳定 |
| 灵魂 | 灵魂残响、连续性印记、信息保真 | 遗产、身份、传奇装备、情报可信度 |

## 9. 与玩家职业的关系

不同职业不只是使用成品技术，而是从不同角度接触规律。

工匠：

- 制造设备。
- 做可复现实验。
- 读取材料记忆。
- 改进结构承载。
- 把规律变成配方和工业标准。

商人：

- 发现资源、材料、设备和情报的价格异常。
- 根据规律预测稀缺性转移。
- 交易线索、设备和实验服务。
- 垄断某类关键催化剂或记录介质。

战士：

- 在战场上制造极端样本。
- 回收残骸、原型机和敌方设备。
- 观察规律在真实冲突中的失效模式。
- 保护或破坏科研设施。

学者/探险家：

- 建立假说。
- 拼接不同文明的观察数据。
- 寻找特殊地理与历史条件。
- 命名规律，推动知识图谱展开。

情报玩家：

- 偷论文。
- 买卖异常报告。
- 伪造或鉴定实验记录。
- 追踪敌方文明技术路径。

## 10. 玩家可见 UI

玩家不应该看到完整规律表。

玩家应该看到：

- 现象记录。
- 实验数据。
- 设备读数。
- 假说节点。
- 已验证关系。
- 理论争议。
- 失败实验。
- 命名权。

知识图谱节点状态：

```text
Unknown -> Anomaly -> Repeated Observation -> Hypothesis -> Reproducible -> Applied -> Standardized
```

文明之间可以共享、交易、偷取或误解这些节点。

## 11. 后台实现建议

后台不需要全量模拟所有规律。更可行的做法是事件驱动。

### 11.1 对象标签

关键对象拥有有限数量的逻辑物理标签：

```text
tags: [
  matter:iron,
  origin:demacia_west_mine,
  memory:battle_fire_low,
  essence:light_weak,
  boundary:porous_life,
  continuity:stable,
  soul:oath_faint
]
```

### 11.2 规律触发器

规律以触发器方式执行：

```text
on_craft
on_refine
on_store
on_transport
on_combat_hit
on_build
on_scan
on_ritual
on_region_tick
on_market_tick
```

### 11.3 观测门槛

现象出现和现象可被看见是两件事。

```text
phenomenon_strength > world_threshold
observer_device_sensitivity + skill + context > visibility_threshold
```

这能解释为什么普通玩家路过看不见，而高阶工匠带着正确设备能看见。

### 11.4 发现进度

发现不应只靠经验条。建议使用证据拼图：

```text
DiscoveryProgress = unique_observations
                  + reproduced_experiments
                  + cross_domain_links
                  + peer_validation
                  + applied_successes
                  - contradicted_results
```

当证据足够，系统不是直接弹出“科技解锁”，而是让文明知识图谱出现一个可命名、可发表、可应用的新理论节点。

发现进度用于记录和表达知识，不作为物理效果的启用条件。未完成理论节点的玩家，只要具备相同材料、设备和实际条件，也能复现相同现象。

## 12. 当前设计结论

玩家可交互物理规律应该满足五个标准：

- 规律来自真实世界的抽象，但被改造成游戏世界独有变体。
- 规律作用于对象、区域、设备、历史和关系，不深入原子尺度。
- 规律能被玩家通过设备和实验部分观察，而不是直接菜单解锁。
- 规律之间可以互相作为观测入口，形成知识图谱而不是线性科技树。
- 规律必须能产生工业、战争、经济、情报和文化后果。

这套系统的核心不是“隐藏多少条终极规律”，而是让规律之间形成可以长期展开的组合空间。玩家发现一个规律，应该像拿到一盏新灯：它不只是照亮自己，还会照到更深处的影子。
