## 1. 本文档解决什么问题

本文档不是用来列出第一批具体规律的。

它定义的是一套“生成规律的规则”：这个世界由哪些统一基本元素构成，这些元素以何种形态存在，它们如何互相作用，为什么大多数日常条件下表现得像真实世界，以及玩家如何通过异常、设备、实验和产业化逐步发现这套统一规律。

核心立场：

```text
统一本体论，分层计算。
```

世界观上，世界只有一套元素和规律。不存在一套“普通 baseline 物理”和另一套外挂式“额外物理”。

统一不要求所有化学性质从更微观的物理推导。基础材料、不可见介质及其宏观化学反应可以直接定义；它们与运动、场效应共享材料状态、数量账目和作用接口，在玩家能够操作与观测的尺度保持一致。

工程实现上，可以把日常世界当成统一规律在常态参数区间里的快速近似。玩家平时看到的重力、动量、火焰、金属、腐败、药效、装备耐久，都不是另一套物理，而是统一规律在低扰动、低浓度、低相位差、低历史负载、低信息精度要求下的稳定表象。

当元素浓度、相位、边界、历史、势差、污染或承载越过阈值时，同一套规律可以表现出异常。异常也可以早已存在于玩家暂时无法到达的地点或取得的材料中；设备精度提升则使原本不可见的异常变得可观测。科研既发生在条件转换中，也发生在抵达、获取和观测能力的扩展中。

```text
统一元素与规律 -> 常态区间 -> baseline 表象
统一元素与规律 -> 异常区间 -> 可观测现象 -> 可控工程
```

如果没有这层元设计，任何单独规律都会像孤岛。玩家可以发现某个现象，但现象之间很难自然交织，也很难从 `gA -> dA` 走到 `gC`。

## 2. 世界模型：统一规律，不是双层物理

### 2.1 Baseline 表象

Baseline 不是一套独立物理，而是统一规律在常态区间中的表象。

它必须和真实世界高度相似，因为这是玩家理解世界、操作世界和信任世界的基础：

- 物体有位置和体积。
- 角色会受重力影响。
- 箭矢有动量和弹道。
- 石头、金属、木头、水和火表现接近日常经验。
- 材料可以被切割、熔炼、储存、运输和消耗。
- 生命体会受伤、恢复、饥饿、中毒、衰老或死亡。
- 城市、建筑、道路、容器和装备遵循稳定的工程直觉。

Baseline 表象的职责是让世界“默认可理解”。玩家不需要先学一套幻想物理，才能知道火会烧、铁会沉、水会流。

这里的“默认”指普通材料、日常条件和玩家早期可接触的环境，不要求所有地点、所有材料和所有技术阶段始终表现为普通重力与普通运动。特殊材料可以埋藏在深层地质中，直到玩家具备相应的开采能力才进入生产与生活；浮石被带回地表并制成悬浮设备，与普通石头继续下落并不矛盾。

### 2.2 异常表象

异常表象不是从外部插入的魔法，而是同一套规律在特殊参数区间中的表现。

异常来自：

- 元素浓度超过阈值。
- 元素比例偏离常态。
- 相位、频率、调性或方向失配。
- 边界条件改变。
- 历史负载积累。
- 信息保真度不足或过高。
- 区域势差形成。
- 生命体、玩家身份或群体记忆参与反应。

设备还可以把原本不可见的变量转成可见读数；除非测量操作本身改变了条件，观测能力提升只改变玩家能知道什么，不改变现象是否发生。

异常表象的职责是让玩家意识到：日常世界只是一个稳定近似，而不是世界的全部。

### 2.3 计算分层

虽然世界观上统一，工程上仍需要分层计算。

建议分为三种计算模式：

```text
Fast Baseline Approximation
Triggered Anomaly Evaluation
Research/Industry Simulation
```

`Fast Baseline Approximation`：处理大多数普通物体和普通行为。用游戏引擎与常规数值规则完成，不追踪复杂元素状态。

`Triggered Anomaly Evaluation`：当对象、区域、设备或事件满足阈值时，读取统一元素状态并计算异常。

`Research/Industry Simulation`：当玩家主动进行实验、生产、鉴定、建设、仪式或战争工程时，进行更细的规则计算。

这样既保留世界自洽，又避免全世界每一块石头都跑完整深层规则。

## 3. 基础材料与不可见介质

这里的“基本元素”允许直接采用材料族作为最小物质类型，不必经过原子形成分子、分子产生化学性质的链路。金属、岩质、纤维、水相溶剂可以是基础材料；以太等肉眼不可见的超自然介质也可以是基础物质。具体采用哪些类型，通过实例化检验，不预先绑定金木水火土或现实化学分类。

基础物质、复合材料、物体和环境量需要区分：基础物质定义响应能力；复合材料记录组分及结合形成的材料相；物体记录形状与连接；环境量描述温度、压力、场强等条件。以太是物质，以太浓度是分布状态，以太势场是作用条件，三者不能互相替代。

可见性不决定是否具有物质性。不可见介质若参与采集、结合或消耗，必须有数量、来源、去向与储运规则；不必拥有普通固体的碰撞体积，也不必直接用普通质量单位表示。

一个底层类型不只是物品名称或设定名词。以太、燃素、暗物质、灵质等候选，以及直接定义的基础材料，都应说明：

- 有存在形态。
- 有载体。
- 有常态表象。
- 有异常表象。
- 有可观测现象。
- 有交互规则。
- 有生产、储存、污染或耗散方式。
- 有至少一种战争用途和一种非战争用途。
- 有能被玩家误解的早期表象。
- 有和其他元素交织的接口。

具体物质可以有不同内部状态，也可以经显式宏观反应形成新材料。状态变量、关系和印记本身不自动成为一种可采集的物质；若要赋予物质性，需补全对应的存在与数量定义。

## 4. 元素定义格式

每个基本元素都应按以下格式定义：

```text
Element {
  id
  hidden_name
  possible_player_names
  real_world_abstraction
  normal_world_analogy
  visibility_and_detection
  quantity_unit
  existence_forms
  carriers
  sources
  sinks
  conserved_quantity
  decay_rule
  interaction_ports
  observation_modes
  baseline_expression
  anomaly_expression
  computation_mode
  industrial_uses
  military_uses
  failure_modes
}
```

其中最关键的字段是 `existence_forms`、`interaction_ports`、`baseline_expression` 和 `anomaly_expression`。

如果一个元素只有名字，没有形态、交互口、常态表象和异常表象，它就不能参与系统。

### 4.1 复合材料与宏观化学定义

```text
MaterialBatch {
  constituent_amounts
  material_phases
  internal_state
}

ReactionRule {
  input_types_and_amounts
  input_phase_requirements
  environment_and_operation_conditions
  rate_and_capacity
  output_phases_and_amounts
  residuals_and_emissions
  state_transition
  heat_or_work_accounting
}
```

材料相是有限定义的结合或组织状态，不是分子结构。新相可以有不同于原料加权平均的性质，同样组分也可因工艺或环境不同形成不同相。反应允许查表和硬编码分支，但相同完整条件的结果一致，产物可以继续参与反应与设备组合。

混合、反应、组装分别结算。未登记反应的组分保留其原有相，不临时生成新性质。普通材料和不可见介质分别按声明单位核算；分割、回收与多反应竞争不得重复使用数量。内部状态保存加工留下的有效结果，无需回放微观过程或完整历史。

### 4.2 材料与相互作用联合定义

新增物质时，应同时给出它参与的作用机制、独立观测入口以及与既有材料的交叉实验。物质与机制是多对多关系，不要求每一种超自然物质拥有专属作用力。

作用机制至少定义：作用对象及条件、读取与改变的状态、数量或能量来源、接触与传播范围、速率和容量、材料响应参数、失效条件，以及玩家能够测得的结果。它们可直接定义在材料尺度，不要求从少数微观作用推导全部化学。

要区分三层职责：机制规定共同的结算关系，材料相规定响应参数与可用接口，反应规则规定新相的形成条件与账目。吸附、屏蔽等交互口的名称本身不构成完整机制。

第一版实例化目前用三类机制试验：结合与交换、介质传递与受力耦合、内部状态演化。由联合检验得到的约束包括：

- 物质量、内部状态、环境场及结构完整度分别表示，不能用一个“活性”值替代所有失效原因。
- 效果随物质量和有效容量合理缩放；材料分件数不能产生额外能力。
- 拦截某种游离物质，不自动意味着屏蔽该物质相关的背景场。
- 减慢内部状态变化，不自动意味着阻止泄漏、修复破损或减慢所有动作。
- 提高观测能力可能消耗样品或改变样品条件；观测工具的影响也按同一规则结算。

需要新用途时，先检验现有材料参数与作用接口是否足够。若仍需新增机制，应给出无法由既有机制解释的可复现实验及新的操作能力；不要只为某个物品名称增加例外。强提示工具的材料规律始终存在，其大后期保底触达策略与物理结算分开。

## 5. 元素存在形态

为了让元素可计算、可交互、可藏在日常世界之中，建议所有基本元素只能以有限几类形态存在。

下列分类描述不同维度，不是互斥物态：一份物质可以同时处于绑定态、具有相位状态并携带来源印记。固液气等物态、存在位置、流动行为及内部有序度应分别表示；不是每种物质都需要全部维度。

### 5.1 游离态

元素弥散在区域中，像湿度、辐射、污染、气味或魔力浓度。

玩法价值：

- 可以被地图、天气、地形和建筑影响。
- 可以被探测器扫描。
- 可以形成资源迁移和区域异常。

### 5.2 绑定态

元素绑定在物体、材料、生命体或装备上。

玩法价值：

- 可以进入制造、交易、鉴定和战利品系统。
- 可以被保存、污染、提纯、转移。
- 可以让物体拥有历史性和出处价值。

### 5.3 流动态

元素沿势差、通道、道路、河流、贸易线、仪式路径或网络移动。

玩法价值：

- 可以形成运输、堵截、导流、截流。
- 可以被城市基础设施控制。
- 可以变成战争目标。

### 5.4 沉积态

元素长期积累在战场、遗迹、矿脉、圣地、墓地、市场或城市中。

玩法价值：

- 可以解释稀有资源点。
- 可以让历史事件永久改变地理。
- 可以成为考古、采集和争夺内容。

### 5.5 相位态

元素不是“多少”的问题，而是处于某种相、频率、调性、方向或关系状态。

玩法价值：

- 可以支持同步、失配、校准、干扰。
- 可以制造“不是资源不足，而是状态不对”的工程问题。
- 可以让设备升级不只是数值提升，而是观测维度变化。

### 5.6 印记态

元素表现为历史、来源、身份、誓言、伤痕、记忆或记录。

玩法价值：

- 可以和 GDD 的身份、遗产、社会性死亡、传奇装备自然相连。
- 可以让某些门、NPC、设备或仪式识别“是不是同一个东西”。
- 可以使伪造、鉴定、继承和背书成为真实玩法。

## 6. 元素交互口

元素之间不直接自由混合。它们通过有限的交互口发生作用。

这些交互口不是现实四大基本作用力，而是面向玩法、工程和发现路径的作用方式。

### 6.1 吸附

一个元素附着到载体上。

例子：战场灵魂残响附着到武器；游离以太附着到晶体。

玩法用途：采集、附魔、污染、鉴定、战利品价值。

### 6.2 解吸

绑定元素从载体上释放。

例子：退火、净化、破坏容器、仪式解封。

玩法用途：资源回收、净化、武器解除污染、反制敌方装置。

### 6.3 流动

元素沿通道或势差迁移。

例子：精粹沿导流槽移动；生命力向生态圣地聚集。

玩法用途：基础设施、封锁、资源迁移、城市工程。

### 6.4 转化

一种元素或形态转成另一种元素或形态。

例子：燃素在特定催化条件下转成热灾污染；灵魂残响固化成誓约材料。

玩法用途：配方、替代资源、经济危机后的新方案。

转化也包括显式的宏观化学反应：材料按数量比例，在特定温度、压力、介质供给或工艺阶段下形成新的结合相。规则可直接定义在材料尺度，无需从原子物理推导；自然形成与人工制造的同相材料遵循相同性质。

### 6.5 催化

元素不被大量消耗，但改变某个转化或绑定过程的门槛。

例子：某矿粉让草药药性稳定；某种污染空气提高海克斯装置效率。

玩法用途：生产技术、专利、供应链、战争后勤。

### 6.6 屏蔽

一个元素或结构阻止另一种作用通过。

例子：暗质矿挡住以太读数；封界蜡阻断灵魂泄漏。

玩法用途：防御、隐蔽、反侦察、设施安全。

### 6.7 共振

两个对象或区域在某个相位、频率、历史或签名上发生同步响应。

例子：同源晶体远距振动；同一场战役中的遗物互相呼应。

玩法用途：通信、定位、锚点、陷阱、伪造。

### 6.8 承载

一个普通世界结构承受统一规律的高负荷异常表现。

例子：时间容器需要稳定框架；城市护盾需要巨构基座。

玩法用途：建筑、工程、攻城、防御、设备尺寸限制。

### 6.9 感染

元素改变载体的后续响应规则。

例子：暗影污染改变药草生长；长期恐慌改变区域灵魂产出。

玩法用途：生态危机、战争污染、医学、区域治理。

### 6.10 识别

元素不改变物理属性，而改变系统对对象身份、来源或资格的判定。

例子：古门识别誓约印记；NPC 识别家族剑；传送锚点拒绝身份断裂物。

玩法用途：遗产、权限、伪造、社会身份、阵营科技。

## 7. 常态表象与异常表象的边界规则

统一规律必须有边界规则，否则系统会变成任意魔法。

### 7.1 常态条件下采用常态表象

普通材料与常态条件下，采用熟悉的重力、运动和材料表现。特殊材料或异常条件满足时，按相应规律计算其效果；常态表象不是对悬浮、局部重力变化或新型运输的永久限制。

基础引擎仍负责对象表示、碰撞与运动结算，异常通过注册接口作用于这些系统。例子：一个物体如果没有碰撞盒，不能因为“灵魂印记很强”就挡住玩家移动；需要物理阻挡的效果必须有对应表示。浮石则可以通过已定义的受力或约束接口支撑物体，无需取消普通重力。

### 7.2 异常必须走表现通道

异常不能随意改写世界，只能通过注册过的表现通道影响玩家体验和系统状态。

建议表现通道：

```text
attribute_modifier
force_and_torque
motion_constraint
durability_change
resource_spawn_rate
resource_quality
crafting_feasibility
device_reading
region_state
npc_recognition
ai_policy_weight
combat_parameter
quest_or_clue_spawn
market_signal
visual_audio_effect
```

如果一个效果找不到表现通道，它不能直接发生。

受力与运动约束通道用于表达悬浮、支撑、锚定等实际物理效果，具体作用范围和结算规则须由对应规律定义。

### 7.3 所有强效果必须有承载体

越强的异常表现，越需要普通世界中的承载体。

承载体可以是：

- 材料。
- 容器。
- 建筑。
- 地形。
- 仪式阵列。
- 设备。
- 生命体。
- 城市基础设施。

这条规则防止“玩家背包里装着城市级奇迹”。

### 7.4 发生与观测分离

现象发生，不代表玩家能看见。

```text
phenomenon_strength > occurrence_threshold
device_sensitivity + player_skill + context_bonus > observation_threshold
```

这让普通玩家、工匠、学者、商人、战士和情报玩家在同一事件中看到不同层次。

### 7.5 局部自洽优先于全宇宙解释

我们不需要解释宇宙如何诞生，但每条规律在自己的适用范围内必须可复现、可反驳、可被工程化。

玩家研究的不是“终极真理”，而是“足够可靠的世界操作手册”。

### 7.6 可调节的技术权衡与深层参数规律

规律系统应提供足够多具有不同作用的参数，使设计者能够调节不同技术路线在主要场景中的竞争关系。目标是没有一条路线在所有主要场景都占优；允许某条路线在特定地区、阶段或任务中明显领先，也允许新发现改变原有优势。

参数应能分别影响不同工程选择，例如载重、速度、距离、能耗、材料需求、设施投入、环境适应性和受干扰程度。参数数量本身不保证平衡；必须在明确的主要场景中比较完整方案及其建设、运行成本，检查优势是否存在可调节的权衡。

表层规律中的参数可以由更深层规律决定。早期玩家在有限材料、地区和测量精度下，将某个参数视为常数；当开采、抵达或观测能力提高后，才发现它随隐藏状态变化，并进一步研究如何控制这种变化。

```text
表层近似：Effect = F(inputs; k_local)
深层关系：k_effective = G(hidden_state, material_state, environment; designer_parameters)
实际效果：Effect = F(inputs; k_effective)
```

以上是关系示意，不是已定稿的物理公式。例如，浮石单位材料的承载系数早期看似固定，后续实验发现其取决于某个隐藏场与材料状态，进而出现新的加工、增效或干扰技术。

设计时需明确：

- 表层参数的作用、范围和近似恒定的适用区间。
- 若存在深层依赖，它读取哪些有限状态、何时更新，以及如何产生可复现的偏差。
- 玩家通过什么新能力区分这些偏差，又能否进一步干预它们。
- 深层技术如何改变路线优势，以及仍可用于调节竞争关系的限制和代价。

设计者配置的参数，与玩家能够发现或改变的世界状态应分别定义。发现深层关系不会让规律临时改写；相同完整条件始终按相同版本的规律结算。后台可使用查表或分段函数，依赖层数与求值范围必须有界，不要求无限向更深层递归。

## 8. 逆向设计流程

这个系统应该逆向设计。

不要先把元素埋进地图，再补理由。应该先设计统一元素网络、交互规则和常态/异常边界，再把它们渲染到日常世界中。

### 8.1 第一步：定义统一规律网络

先在设计后台定义：

```text
ElementGraph
InteractionRules
ExpressionThresholds
ExpressionChannels
DiscoveryDependencies
ApplicationFamilies
CountermeasureFamilies
```

这里可以出现设计师知道、玩家不知道的真相。

### 8.2 第二步：定义常态约束

对每条元素和交互规则，先问它为什么在普通世界中没有让世界崩坏。

需要定义：

- 常态浓度范围。
- 常态相位范围。
- 常态边界条件。
- 常态衰减速度。
- 常态承载上限。
- 普通材料为什么足以稳定它。
- 普通生命体为什么不会持续触发异常。

这一步的目标是让统一规律在 baseline 条件下表现得像真实世界。

### 8.3 第三步：选择异常表达点

把统一规律的异常表象放到玩家实际能接触的地方：

- 矿物。
- 草药。
- 战场残骸。
- 建筑材料。
- 天气。
- 地形。
- NPC 行为。
- 玩家身体状态。
- 装备耐久。
- 交易价格。
- 谣言和情报。

这些不是“投影点”，而是同一套规律在特殊条件下的可见表达。

### 8.4 第四步：制造早期误解

每条规律都应该有合理的错误解释。

例子：

- 玩家以为某种矿物“更轻”，其实是暗质改变了测量条件。
- 玩家以为某种草药“随机变质”，其实是生命相容性受月相和容器边界共同影响。
- 玩家以为某件武器“诅咒”，其实是灵魂残响和连续性印记冲突。

误解不是欺骗玩家，而是让科学路径有层次。

### 8.5 第五步：设计设备链

观测设备应该回答一个有限问题，而不是直接揭示规律真相；开采、加工和实验设备则应明确它使哪些原本不可行的操作成为可能。

```text
dA: 能看见 A 维度
dB: 能看见 B 维度
dC: 能比较 A 与 B 是否同源
dD: 能在小范围复现实验条件
```

设备链使规律发现变成逐步加深的工具史。

其原则是：能力进步让发现变得可行。能力包括抵达地点、取得样品、处理材料、维持实验条件和提高观测精度；科技树记录这些能力之间的依赖，不作为自然规律是否生效的开关。

例如：

```text
掌握特殊耐磨材料的加工 -> 制作深钻设备 -> 穿过普通工具无法开采的岩层
-> 取得深埋浮石 -> 观察与复现悬浮 -> 制造运输设备 -> 探索新的地点或参数区间
```

浮石及其规律在被发现前就已存在。若玩家通过交易、合作或其他符合世界规则的方式取得样品或设备，也应能观察同样的现象，不要求先完成相同的个人科技节点。

见过现象、理解规律、制成样机和稳定量产是不同进展。理解尚不完整时也可以偶然利用现象；深入研究应提高复现、预测和工程应用能力。

### 8.6 第六步：反向检验发现路径

对每条隐藏规律，反问：

- 玩家第一次会在哪里看到它？
- 玩家会如何误解它？
- 哪个职业最早能利用它？
- 哪个设备能把误解推进成假说？
- 哪种抵达、采样、加工或观测能力使这次发现成为可能？门槛是否来自实际条件？
- 哪两个以上路径能从不同侧面观察它？
- 掌握规律后，是否能制造新设备去发现更深规律或识别原先被当作常数的参数？
- 新应用在哪些主要场景占优，在哪些场景受限？哪些参数能调节这些权衡？
- 它是否有工业、战争、经济、情报和文化后果？
- 它是否有反制方式？

如果一条规律只有发现，没有利用；或只有利用，没有反制；或只能从单一路径发现，它还不够成熟。

## 9. Corner Case 处理原则

因为统一规律的复杂部分定义在高级对象上，而不是原子尺度，所以必须提前处理边界情况。

### 9.1 分割

当一个对象被切开、拆解、熔炼或分解时，深层属性如何继承？

原则：

- 数量型属性按质量、体积或价值分配。
- 印记型属性按“主连续体”继承。
- 污染型属性可以按接触面扩散。
- 信息型属性会因分割损失保真度。

### 9.2 合并

当多个对象被合成、熔炼、修复或堆叠时，属性如何合并？

原则：

- 同类数量可加和，但有饱和上限。
- 相位类属性可能相消或失配。
- 历史类属性可能冲突，产生噪声。
- 高等级工艺可以保留主材料来源链。

### 9.3 容器

容器和内容物之间必须有边界规则。

问题：

- 内容物的元素会不会泄漏？
- 容器会不会被污染？
- 容器是否屏蔽观测？
- 玩家交易时买的是内容物，还是连同容器的状态一起买？

### 9.4 库存与离线

放进背包、仓库、邮件、拍卖行或离线角色身上的对象，不能完全暂停世界规律。

原则：

- 高频变化冻结或降采样。
- 低频衰变继续结算。
- 市场可见对象保留可鉴定状态。
- 关键异常对象需要防复制、防刷新的唯一性策略。

### 9.5 复制与模板

如果玩家能记录蓝图、拓印、复制或批量生产，必须区分：

- 形状复制。
- 工艺复制。
- 材料状态复制。
- 历史印记复制。
- 身份连续性复制。

大多数设备只能复制前两者。后几者需要更深规律，且必须有损耗和法律/社会后果。

### 9.6 玩家身体

某些元素可以和玩家本身相互作用，但必须谨慎。

可允许的通道：

- 状态效果。
- 适应性。
- 感知阈值。
- 技能解锁条件。
- 重生/遗产系统。
- 阵营或 NPC 识别。

不建议直接修改：

- 基础移动模型。
- 账号级永久惩罚。
- 无法反制的硬控制。
- 无提示的长期负面积累。

其中对基础移动模型的限制指避免绕过角色控制与运动结算，不排斥通过明确支持的载具、受力或运动约束实现悬浮运输等能力。

### 9.7 跨区域搬运

对象从 A 区域搬到 B 区域时，它携带哪些深层状态？

原则：

- 绑定态随物体移动。
- 游离态主要留在区域。
- 沉积态需要特殊容器才能搬运。
- 相位态可能因地理环境失配。
- 印记态可搬运，但会被新历史覆盖或污染。

## 10. 元设计验收标准

一组统一元素和规律，只有满足以下标准，才算适合进入正式设计：

- 它们能被有限数据结构表示。
- 它们有清楚的存在形态。
- 可见材料与不可见介质都有明确的数量和检测方式，物质与环境场不会混为无来源的加成。
- 它们通过有限交互口互动。
- 复合材料有相、状态和数量定义，反应结果能够继续参与共享规则，而非只能用于单一物品配方。
- 隐藏物质与作用机制有独立观测入口及交叉实验；已经声明的用途不能超出实际定义的作用范围。
- 它们在常态区间能表现得像真实世界。
- 它们在异常区间能产生可观测、可实验、可工程化的现象。
- 它们通过有限表现通道影响玩家体验和系统状态。
- 它们有多条发现路径。
- 发现门槛来自实际能力与条件，规律不依赖个人科技节点才开始生效。
- 它们有多种应用场景。
- 技术路线在主要场景中有可调节的优势与代价，不存在覆盖所有主要场景的全优路线。
- 表层参数有明确的适用范围；若受深层规律支配，其依赖可计算、变化可验证，且不会因玩家完成发现而临时改变。
- 它们有反制和失败模式。
- 它们能解释 GDD 中经济、战争、身份、情报和科研系统的至少两个模块。
- 它们在对象分割、合并、容器、库存、复制、玩家身体、跨区域搬运时有默认规则。

## 11. 下一步

第一版 `ElementGraph` 通过具体材料、反应和设备实例迭代形成，不要求先完整定稿图谱才能检验玩法与计算边界。

当前试案见[底层材料与化学规律：第一版实例化](material_chemistry_first_instantiation.md)。它选取五种可见基础材料和两种不可见介质，检验复合反应、地理分布、能力发现链与深层参数；这些候选不代表已定稿的世界物质表。

每轮实例化需补齐：

- 存在形态。
- 载体。
- 来源。
- 去向。
- 交互口。
- 常态表象。
- 异常表象。
- 表现通道。
- 最早可观测现象。
- 战争用途。
- 非战争用途。
- 与至少两个其他元素的交互。
- 宏观反应、复合相、数量账本与内部状态。

用具体反应、设备链和发现路径检查图谱，记录不能组合、数量不闭合、发现依赖循环或计算成本不清楚的地方，再修订元素与规律。纸面闭环通过后仍需原型验证。
