## 1. 本文档解决什么问题

本文档不是具体元素表、配方表或已实现的自动生成程序。它定义一套“生成规律的规则”，并规定候选自然如何被表达、实例化、执行和验证。

目标是生成一种计算上可负担、在玩家可操作尺度上具有丰富因果结构的自然。玩家通过这套自然改变物质、制造设备、研究规律并扩展可用资源，而不是通过完成个人科技节点，获得对原本不生效的规则的使用许可。

核心立场：

```text
统一本体论，分层计算。
少数共同机制，不等于少数材料种类。
设备改变实际条件，知识改变可行方案，发现不改写自然。
```

世界只有一套元素与规律。不存在一套普通 baseline 物理和另一套外挂式额外物理。这里的基础规律可以直接定义在宏观材料、物种、有限内部状态与场的尺度；其下不必假定存在尚待实现的现实原子模型。

现实世界是常态体验的参照，不是所有基本机制必须具备的来源。完全原创的作用可以合格，只要它有明确的状态、账目、边界、可复现现象与组合规则。设计者同时需要说明：哪些日常行为保持熟悉，哪些差异属于这个世界的自然特征。

一个候选世界实例至少交付：

```text
WorldInstance {
  law_version
  common_mechanisms_and_fields
  element_and_species_catalog
  material_phases_and_reactions
  initial_material_distribution_and_background_sources
  observation_and_operation_models
  engine_bindings_and_numerical_contracts
  discovery_and_resource_transition_test_cases
}
```

上述项目共同描述一个实例，不要求使用自动搜索算法生成，也不要求先把所有内容写完再开始原型。实际世界由规律、初始条件、外部通量与持续行为共同演化；科技记录、任务状态和界面是否打开，不是物理更新函数的隐含开关。

```text
共同规律 + 真实世界状态 + 操作与外部通量 -> 下一时刻状态
真实状态 + 仪器状态 + 测量操作 -> 可观察结果
能力、知识与组织变化 -> 可执行工艺集合变化 -> 有效供应与竞争格局变化
```

具体元素名称、数量、极旋作用的方程、浮晶组成和七阶段资源史，仍是实例化候选，不在元设计中固化为所有世界必须采用的答案。

## 2. 世界模型：统一规律，不是双层物理

### 2.1 Baseline 表象

Baseline 是统一规律在常用材料、日常条件与初始技术能力下的表象，不是独立物理，也不是以后不得突破的表现上限。

初始世界可以采用约公元1000年的生活与工程能力作为设计参照，不要求复刻某一真实地区的历史技术清单。普通环境至少应具有稳定、可学习的操作直觉：物体有位置和体积；角色受重力影响；箭矢有动量和弹道；常见石、金属、木、水和火具有熟悉行为；材料可以被切割、熔炼、储存、运输和消耗；生命、容器、建筑与道路有明确的工程边界。

设计者先列出开局已经存在的物品、混合物、化合物、工艺、设备与自然异常，再检验共同规律能否支持它们。普通土壤、矿石和海水不能因早期用途简单，就自动成为不可再分的本源。

不同地区可以有不同的初始材料相与环境条件。高原可以较早取得天然浮晶，河谷可以较早拥有持续水力。天然环境已经形成的复杂材料允许被先利用、后理解，不要求所有文明按相同顺序发展。

### 2.2 异常表象

异常是对现有经验、理论或测量能力而言的异常，不是程序必须等越过某个“魔法阈值”才开始执行的第二套规则。

异常可能来自浓度、比例、相位、方向、温压、边界、区域势差、污染、加工历史或活体动态状态；也可能只是此前无法到达、取样或分辨的普通规律后果。微弱作用可以一直存在，经过时间积累或更精密测量才变得可见。

隐藏可以由以下可计算条件造成：埋深与围岩、难处理结合态、样品获取时泄漏或结构破坏、相反方向互相抵消、频段不匹配、多个因素混淆、边界选择性、观察者扰动、历史状态与关系不可直接读出。

天然异常进入日常生产以后可以成为常见技术；“异常”不是永久稀有品质。观察能力改变能知道什么，除非测量操作实际扰动样品，否则不改变现象是否发生。

### 2.3 计算分层

保留三种工作模式，升级为同一世界状态的数值近似合同：

```text
Fast Baseline Approximation
Triggered Anomaly Evaluation
Research/Industry Simulation
```

`Fast Baseline Approximation`：计算稳定或低扰动情况的有效行为。可以使用聚合批次、缓存参数、事件步进与常规引擎，不要求逐物体展开全部化学。

`Triggered Anomaly Evaluation`：当状态变化、耦合增强、误差边界或事件条件要求时，提高求值细度。触发的是计算方式，不是自然规律本身。

`Research/Industry Simulation`：处理主动实验、复杂生产和需要更多空间分区的过程；自然发生的同类过程同样适用，不能只在玩家打开实验界面后才执行。

每种近似需声明：适用范围、保留状态、误差边界、更新时间、模式转换方法，以及不会丢失的长期积分量。跨模式须保持组分、声明守恒量、内部状态和对象连续性；近似结果在目标观测精度内应与参考计算一致。

低浓度不等于不存在。微量组分可以保存在批次或区域账本，不得因显示精度、距离或阈值裁剪而删除。可采用基于固定世界种子、条件分布和总额约束的延迟细化，但不同玩家、不同采样顺序、读档和地块细分不得重新抽取可开采总量。

离线、远距、背包与拍卖行采用降采样或解析推进时，仍需结算有关泄漏、反应、衰变和转移；不能把这些状态切换做成免费保存技术。

## 3. 基础材料与不可见介质

“基本元素”指本实例选定的可追踪本源组分，不要求等于现实原子。选择时必须同时满足化学辨识、资源赋存、分离路线、材料响应和计算成本的需要。

材料族可以作为聚合视图，或者在明确声明的建模边界内作为不可再分本源；但不能一方面把“金属”“土”“水”设为不可分类型，另一方面要求玩家从中发现并分离未被记录的组成。计划包含的深层成分必须从世界初始化时就存在于状态或受约束的生成账目中。

| 层次 | 定义与职责 |
| --- | --- |
| 本源组分 `Element` | 数量单位、守恒或转化声明，以及可参与的结合和作用范围。 |
| 化学物种 `Species` | 组成向量、允许结合形式、带荷及反应定义；可以使用宏观符号而不模拟分子。 |
| 材料相 `MaterialPhase` | 已定义的结合或组织状态、物态、结构及有限内部状态下的响应。 |
| 混合物／材料批次 `MaterialBatch` | 多个相及各自数量、空间分区和加工状态。 |
| 物体／器具 `Object/Device` | 几何、表面、连接、容器和操作能力。 |
| 场与环境量 `Field/Environment` | 具有明确源与更新规则的场，以及温度、压力等条件。 |
| 历史／连续关系 `Trace/Relation` | 独立登记的状态或关系；不自动成为可采集物质。 |

世界可以有多于首轮原型的元素与大量物种，而只采用少数共享机制。增加元素应提供可辨识的化学、赋存或响应差异，不只是制造更多只供一种高级道具使用的钥匙。元素数量不设为五种或十八种的固定目标，依据实例检验扩展。

同一战略元素可以存在于稀少但易处理的天然化合物、广泛但难分解的矿相、稀溶液、气体、吸附层、生物体和工业废物中。并非每种元素必须具有全部来源，也不要求每个地区都含有全部元素。

可见性不决定物质性。以太等不可见介质若参与采集、结合或消耗，必须有数量、来源、去向与储运规则。物质量、极荷或其他源状态、储能、内部有序度与场强分别表示；以太介质不等于场，燃素数量不等于充能程度，灵魂载体不等于活体身份。

活体主动维持的灵魂结构、可保存的残响和可制造的耦合材料应分别定义。不得仅因某材料可以与灵魂作用，就假定它能够制造或复制身份。

## 4. 元素定义格式

每个基本元素至少按以下格式定义。现实抽象是可选参照，而非合格条件。

```text
Element {
  id
  hidden_name
  possible_player_names
  real_world_abstraction_optional
  quantity_unit
  conserved_quantities_or_explicit_transmutation
  binding_and_species_families
  mechanism_participation
  occurrence_forms_and_sources
  sinks_or_export_destinations
  visibility_and_detection
  baseline_expression
  potential_anomaly_expressions
  computational_representation
}
```

用途应在元素、材料相与设备族的联合实例中检验。一个系统需要跨工业、战争、经济、身份等场景的用途，不强制每个本源组分单独具有一种武器效果。

### 4.1 复合材料与宏观化学定义

```text
Species {
  id
  constituent_vector
  allowed_phases
  charge_states_or_other_source_states
  binding_and_reaction_interfaces
}

MaterialPhase {
  id
  species_and_composition_constraints
  physical_state
  structure_and_order_model
  internal_state_schema
  stability_and_formation_windows
  mechanism_response_models
  transport_and_boundary_properties
}

MaterialBatch {
  phase_amounts
  constituent_ledger
  compartments_or_spatial_distribution
  temperature_and_energy_state
  source_states_and_bound_medium_amounts
  structure_surface_contamination_and_history
}

ReactionRule {
  input_types_and_amounts
  input_phase_and_contact_requirements
  environment_and_operation_conditions
  rate_capacity_and_competing_reaction_allocation
  output_phases_and_amounts
  residuals_emissions_and_destinations
  state_transition
  heat_work_and_other_conserved_quantity_accounting
}
```

材料相是有限定义的结合或组织状态，不要求原子排布模拟。新相可以有不同于原料加权平均的响应；同样组分也可因工艺或环境不同形成不同相。反应允许查表和有限分支，但其条件必须读取实际材料、环境与操作，而非物品名字或任务进度。

混合、反应、相变、成形与组装分别结算。研磨改变粒度和结构，不自动等于化学分解。未登记反应的组分保持已有相或按明确混合规则共存，不生成临时新性质。

普通化学默认守恒本源组分；若实例允许嬗变、衰变或特殊来源，需以独立机制明确输入、输出、单位与代价，不能借“转化”一词省略账目。物质散失到环境、进入废气或变成难回收状态，不等于凭空销毁。

过程连续推进或按有界事件步进。中断、取样、换容器和转移后，已经生成的产物、剩余原料、副产物及内部状态必须保留。多反应竞争不能重复使用同一份数量。

自然形成与人工制造的同相、同结构、同状态材料遵循相同响应。来源和连续性有独立规则时可形成差异，但不能用“天然”标签永久保留额外性能。

### 4.2 材料与相互作用联合定义

先定义共同作用的有效范围与结算关系，再定义不同元素、物种、相及结构如何响应。设计可以来回迭代，但正式规格不得只由特殊材料的能力列表拼成。

```text
InteractionMechanism {
  id
  source_states_and_participating_objects
  state_read_set_and_write_set
  interaction_or_transport_operator
  contact_range_propagation_and_boundary_rules
  response_parameter_schema
  quantity_energy_momentum_or_other_accounting
  rate_capacity_and_failure_modes
  independent_observation_and_cross_material_tests
  numerical_contract
}
```

三层职责继续保持：机制规定共同结算关系，材料相规定响应参数与适用接口，反应规则规定新相形成条件与账目。化学不必全部从场方程推导，但必须与场共享一致的状态及物料、能量约束。

本目标实例应具有至少一种可跨普通与特殊材料使用的非接触场作用，使受力、传导或输运、感应、传播、探测与分离等能力可以在明确适用条件下相互连接。近期讨论的“极旋作用”是候选实现；本规范不固定名称、方程，也不要求照搬现实电磁学。

每种场需额外定义：源、传播或求解方式、场的有效状态、材料耦合、边界行为、能量及动量交换对象。中性不自动等于无响应；同频不自动等于无距离限制的传能或传送；拦截介质不自动屏蔽相关场；把发生器和执行部件装在同一载具内不能凭空产生净外力。

若空间通行需要新的邻接或连续性公理，必须单独登记并给出可区分实验，不能把“共振更强”当成足够说明。灵魂及身份机制也可以独立存在，不要求被强行还原为同一种场。

新增用途先检验既有机制与材料响应。新增机制需提供既有机制无法解释的可复现实验与新的操作能力，不为单个道具名新增特权。

### 4.3 固液气、气相化学与状态路径

物态、化学物种、材料相、空间分布、带荷状态和有序度分别表示。气体不是一种新增本源元素；游离态也不是气态的同义词。

气体区域至少记录：各物种数量、有效体积、温度、压力模型、连接与边界交换，以及需要的载荷或激发状态。气体、蒸汽、悬浮液滴和烟尘按各自表示区分，不能用同一粒子特效替代。

每个需要跨物态的物种登记：可达相变与分解路径、温压依赖、溶解／吸附与释放、壁面反应、相关热或功账目。相图可用有限温区、压力段和规则表，不必具备现实化学的完整精度。

气相工艺必须能够进入共享设备网络：挥发、冷凝、密闭收集、气相反应、吸附、载荷分离和沉积。排出的气体进入实际容器或环境库存。过滤烟尘不等于分离气体，抽去空气不等于清除所有场。

密闭体系的蒸发、泄漏、加热与化学气体生成共同影响压力；泄压、安全阀和容器破坏都按同一状态模型计算。

## 5. 元素存在形态

保留以下六类描述，作为正交维度而非互斥物态。固液气与物种、材料相、位置、流动、内部状态及关系分别表示，不要求每种物质使用全部维度。

### 5.1 游离态

物质弥散在区域介质中，有实际库存或受约束的密度分布。可被天气、地形、建筑、吸附与流动改变，并产生探测、资源迁移和污染玩法。

游离物质与场分开；没有被玩家看见的库存仍然存在。

### 5.2 绑定态

组分以化学结合、吸附、包埋或明确登记的其他方式附于载体。不同绑定方式采用不同释放与转化条件。

可进入制造、交易、保存、提纯与污染系统；载体的历史不自动成为绑定物质的历史副本。

### 5.3 流动态

数量在区域、容器和网络之间移动。流动依据对应的势差、动力、通道和边界规则。

贸易线、道路和仪式路径是可能的载运结构，不自动等于无载体的物理输运。需明确谁或什么搬运了什么，速率、容量、损失与目的库存是什么。

### 5.4 沉积态

物质通过地质、环境、生物或社会活动长期富集于某处。矿脉、尾矿、废弃工坊和旧战场可以成为资源来源，但富集有来源、数量和形成过程。

沉积不自动意味着必须使用特殊容器搬运；实际的结合、稳定与泄漏条件决定采集方式。

### 5.5 相位与有序状态

材料具有方向、相位、频率、调性及有限内部组织状态。它们可以支持同步、干扰、校准和“数量足够但状态不对”的问题。

内部状态不取代物料账目。物相、振荡相位与对象间关系分别定义，不能因都使用“相”字而混为一类。

### 5.6 印记与连续关系

物体、载体或活体可保存有限历史、来源、身份与连续性状态。它们与 GDD 的身份、遗产、鉴定和传奇装备连接，但不是所有印记都可作为物质收集。

物质本身、被保存的信息、持续活跃的灵魂结构，以及两个对象间的关联，可以同时存在，须分别表示。

## 6. 元素交互口

交互口是共同机制向材料、结构与操作开放的接口词汇，不替代机制本身，也不代表只能给登记为“设备”的物体使用。

接触、浸泡、开放表面、场和实际边界可以建立交互关系。一块普通石头没有设备插口，也能被加热、浸泡和测量。显式端口适合管道、轴系、密闭连接与信号线；它们不是自然能否作用的许可。

### 6.1 吸附

物质在载体上积累；需定义选择性、容量、速率、竞争组分和表面状态。达到容量后不再凭空吸收。可用于采集、分离、污染和检测。

### 6.2 解吸

已绑定或吸附数量进入其他明确库存。需定义环境、操作、速率和代价，可用于回收、再生与净化。不同绑定方式不自动共用一种解吸条件。

### 6.3 流动

物质、载荷或其他已定义量沿相应网络转移。需区分运输信息、运输介质与运输可用功，不能因远端收到信号就获得无限动力。

### 6.4 转化

材料按反应、相变或结构更新规则改变。普通化学不改变本源组成总额；嬗变或特殊来源另行声明。反应的副产物和排放可继续参与其他规则。

### 6.5 催化

材料改变指定反应的动力学、可达路径或实际操作条件。需说明选择范围、污染、失活与再生；不能因被称为催化剂就自动提高所有产率或免除能量账目。

### 6.6 屏蔽

特定材料和结构改变指定作用的通过、反射、吸收或耗散。必须区分物质流、波、背景场及身份信息，不能以一个“屏蔽值”包办。

### 6.7 共振

对象对相应激励产生频率或相位相关响应。普通传播和具有连续来源的特殊关系分别登记；共频、同源、共享历史不能未经规则直接互相替换。

### 6.8 承载

结构承受力、压力、温度、场、介质或其他负载。需定义几何、材料、容量、稳定范围和失效，允许新材料与工艺改变设备尺寸与性能。

### 6.9 感染

接触或传播过程改变载体状态，从而改变后续响应。改变的是已有规律读取的状态，而不是为被污染对象临时生成新自然法则。

### 6.10 识别

设备或 NPC 根据可观测信息、印记和权限制度作出判定。自然的连续性关系与社会的合法性判定分开；认识名字或拥有任务资格不自动改变相同材料的物理响应。

## 7. 常态表象与异常表象的边界规则

### 7.1 常态条件下采用常态表象

普通材料和条件具有熟悉行为；特殊材料和参数采用同一机制的响应。基础引擎负责受支持的对象表示、碰撞和运动积分，材料内核提供实际受力、约束、状态与过程更新。

需要阻挡的效果有对应空间表示；悬浮经受力或明确约束实现；传送若被允许，按登记的空间规则事务化处理。不能通过无来源的属性修改绕过这些接口。

### 7.2 表现通道与写入权限

将原本混在一起的通道分成三类：

| 类别 | 示例 | 约束 |
| --- | --- | --- |
| 自然状态写入 | 材料转移、相变化、热与功、场源、受力、结构损坏、明确空间关系 | 必须由规律与真实操作产生，并保持账目。 |
| 观测与呈现 | 仪表读数、可见颜色、声光、实验记录、界面汇总 | 从状态和观测模型生成，不能反写样品真值。 |
| 社会与叙事响应 | NPC识别、AI决策、订单、价格信号、任务与线索 | 可以响应真实状态或角色认知，不直接篡改物理结果。 |

`resource_spawn_rate`、`resource_quality`、`crafting_feasibility`、`market_signal` 等不得作为自然层任意改写资源和产出的后门。资源产生需有来源过程；品质需对应实际材料状态；工艺可行性是操作条件的判断；价格是供需与制度结果，而非元素的基础属性。

AI可以组织勘探、生产、运输、开放已有设备、传播已存在规律的知识，也可以发动符合规则的事件。版本更新或运营纠错属于显式管理行为，应记录版本、迁移与补偿边界，不假装是玩家通过实验发现的规律改变。

### 7.3 强效果的来源、承载与尺度

强效果需明确来源、供能、承载、耦合、影响范围与失效条件。载体可以是材料、设备、容器、建筑、地形、生命体或基础设施。

不把“高阶能力永远必须巨大或不可便携”写成元公理。材料、工艺和外部基础设施可以使设备小型化；但小型终端调用远处大设施时，也必须计算真实外部支撑和限制。

设计对象是完整方案的资源和尺度约束，而不是永久固定某种载具或建筑的生态位。

### 7.4 发生、观测与解释分离

```text
physical_state_next = Update(physical_state, operations, external_fluxes)
measurement = Observe(physical_state, instrument_state, operation, noise_model)
knowledge = Interpret(measurements, prior_models, analysis)
```

真实相变或反应阈值属于规律；仪器量程、精度、积分时间与噪声属于观测；知识节点属于解释与共享。不能把三者写成同一条等级判定。

技能可以改变实际操作误差、可执行校准和分析能力；角色身体或灵魂确实参与测量时，须以可检验状态表示。不能仅因账号研究等级不同，让同一仪器对同一输入产生不同的隐藏真值。

允许已声明的随机过程与噪声；相同条件需服从同一条件分布，世界中已确定的资源状态不得通过重开界面、重登或换观察者重新抽取。物理复现、统计复现与知识认定分别检验。

### 7.5 局部计算，全局账目与组合自洽

不要求解释宇宙诞生，也不要求从微观演算所有宏观效应。但各自合理的反应、场和设备组合以后，仍需遵守统一数量与能量义务。

需要检查：加工—回收循环、充能—做功循环、场源—执行器反作用、分割—合并、运输—相变、储存—离线，以及连续关系的创建和使用。开放体系须记录外部源与汇；依赖自然场或环境储能不等于有无限功率。

不得用市场价格、道具稀有颜色或系统希望的掉落量替代物理账目。

### 7.6 技术权衡、稀缺变化与深层参数

比较对象是完整技术方案，而不是单个元素名或固定时代等级。比较载重、速度、距离、功率、能耗、材料规格、建设投入、维护、场址、环境与干扰。

允许某条路线在特定地区或阶段领先，也允许新技术全面淘汰某种旧工艺。保持有意义的选择，不等于每项旧技术必须永久占据优势场景；材料优势也不应被固定为所有参数都更优的品质梯度。

表层参数可以由隐藏状态决定：

```text
Effect = F(inputs; k_effective)
k_effective = G(material_phase, structure, internal_state, environment; law_parameters)
```

需说明近似恒定区间、偏差、可观测证据、控制方式和计算范围。依赖有界，可查表或分段求值。发现不改写参数；调整设计参数必须作为明确版本变更。

技术性稀缺可以被消解。不得为维持既定刷取时间，在效率提高后无理由减少真实矿量、增加无关稀有配料或恢复原有成本。

## 8. 逆向设计流程

本系统逆向设计体验约束与初始世界，再正向验证共同自然。不是先随意放矿再补故事，也不是必须先完成一张抽象元素表才能开始实例化。

### 8.1 第一步：定义初始世界与能力目标

列出约公元1000年参照下的常见混合物、化合物、工艺、器具、已可见异常和地区差异。另列期望可达的能力族，如水力深采、动力运输、远距观测、通信、场操控、空间通行和活体控制。

能力是生成规律时的设计目标，不是运行时强制指定的唯一配方或统一解锁顺序。天然材料允许某地区跳过另一地区需要工业完成的步骤。

### 8.2 第二步：提出共同机制并联合构造物质网络

先明确机制的源、状态、作用关系和账目，再让元素、物种与相提供响应差异；通过具体材料反复修订二者。

交付至少包含：`MechanismGraph`、`ElementSpeciesPhaseGraph`、`ReactionNetwork`、`ObservationModels`、`OperationInterfaces`。共同机制不要求推导全部化学；具体表项则不得相互矛盾或借物品名称产生特权。

### 8.3 第三步：从常见材料反推共同本源与赋存环境

检验初始材料是否能由这些组分、形成路径与地理条件支持。常见土壤、矿石、海水、气体和生物原料都是已存在的物质状态，而非等待科技阶段填充的空白容器。

同时构造稀少但易处理的天然化合物、广泛但难处理的赋存相，以及可通过更高能力利用的废料或稀溶液。天然相与人工相共用材料规则。

环境是天然加工条件：排盐、沉积、温压周期、介质来源、生物富集和稳定保存可以产生不同初始材料。允许直接生成合理的地质初态，不要求实际模拟千年过程；初态仍应具有一致来源、总量及之后的演化条件。

### 8.4 第四步：设计可证伪误解和交叉实验

为关键规律登记早期解释、替代解释、能够区分它们的操作与仪器，以及至少两个具有实际差异的发现入口。

例子：称重减小与惯性不变；失载来自缺少介质、化学污染还是结构变化；同样组成为何形成不同功能相；离体残响与主动续相如何区分。

研究不必始终由怪异现象驱动。原料成本、材料失效、重复生产偏差、尾气损失和新地区样品，同样可以提出有价值的问题。不能为了防攻略使同一共享样品的真值因玩家身份改变。

### 8.5 第五步：设计开放设备链与工业化路径

能力进步使抵达、采样、提纯、供能、维持条件、测量和批量生产变得可行。科技图记录这些依赖，不控制自然是否生效。

```text
实际操作能力 -> 新样品或条件 -> 观测与比较 -> 假说与实验
-> 可迁移的解释 -> 新设备族 -> 新的材料、环境和生产问题
```

见过现象、偶然利用、解释规律、制成样机、稳定量产分别记录。交易、合作、购买设备与获得知识允许改变进入路径；后来者不必重复所有低效劳动。

每个设备说明输入的能量或物质、施加的边界与操作、连接方式、容量和失效。炉子提供热与气氛，过滤器提供选择性通道，不直接提供某一种成品的兑换权限。

工艺蓝图记录操作程序、原料规格、设备结构、调控与终点条件。自动化和NPC执行可把成熟过程封装成输入输出界面，但过程仍可展开、修改、中断、取样和诊断，不能变成免除底层规则的生产函数。

### 8.6 第六步：正向检验发现、组合与可达性

从每种代表开局向前运行：是否有可取得的样品、启动功率、容器、工具与替代入口？是否存在“先有高级设备才能得到制造第一台高级设备的材料”的封闭依赖？

静态图连通不等于工程可达。还需检查样品与工业数量、材料规格、回收率、能耗、处理能力、设备寿命、物流和工序先后。贸易可以是显式路径，但需说明可能的外部供应，不能把不存在的卖家当作启动条件。

一条隐藏规律应产生新的操作能力并连到其他系统；已经成立的实验应能在异地或替代设备上按相同条件复现。应用可有失效和反制，但不要求每种物质都被设计为一件武器。

### 8.7 技术条件下的稀缺与资源生成

资源不是一个固定稀有度标签，而是物质分布与实际能力共同形成的可用供应。知识改善寻找与方案选择，设备扩大可行操作，二者不在后台给相同工艺附加无来源回收率。

每种战略资源至少提交一份资源转化记录：

```text
ResourceTransition {
  element_species_or_functional_state_target
  initial_occurrences_and_total_ledger
  geological_or_environmental_indicators
  early_accessible_compound_or_natural_phase
  widespread_but_difficult_occurrences
  sampling_and_detection_limits
  processing_routes_and_required_capabilities
  recovery_selectivity_throughput_energy_and_consumables
  product_specification_and_process_yield
  waste_streams_and_recycling_routes
  scarcity_relief_and_following_bottlenecks
}
```

区分实际存量、玩家已知存量、物理可达量、可处理量、按指定预算和规格可交付量；不强制它们随时间单调增加。资源耗竭、环境变化、物流和需求都可能改变结果。

物料产率示意：

```text
recovered_amount = feed_amount × target_content × process_recovery
```

它不等于经济利润，也不能忽略完整工艺的试剂、能耗和处理成本。样品可得与工业供应、纯度与成相良率、体积和有效面积规格应分别检验。

早期稀缺可以要求探索和实验投入，但新信息应改善后续选择。不能把不受知识影响的独立随机掉落作为全部科研进步的唯一入口。随机地质使用共同世界状态；地块细化与反复采样不得重掷库存。

技术进步可以提高勘探、处理低品位资源、回收废料、制造天然相或寻找替代结构。允许旧稀缺消失和产地优势转移，不为维持刷取量自动同步增加新门槛。更低成本不保证价格立即下降，市场需求与制度留给经济模型。

自然不会自动保证各阵营公平。需评估初始可达性、单一关键物料垄断和替代方案，把社会竞争与物理真实性分别设计；不得偷偷改变实验结果来补偿弱势方。

### 8.8 最小工程实现路径

采用材料内核、空间设备适配和观测呈现三层职责。可使用批次、容器分区、通道网络与必要局部网格，具体技术由原型决定，不在元设计绑定某个引擎版本。

最小闭环：持续材料状态 -> 加热或反应 -> 取样与转移 -> 改变边界 -> 形成可用材料 -> 装入真实设备 -> 失效、诊断与恢复。

同一批材料离开实验台后继续存在于主世界；不是完成实验小游戏后另发一件奖励物品。设备只改变过程条件，界面、动画和特效不是物料数量的权威来源。

## 9. Corner Case 处理原则

高级对象模型必须明确组合语义，以有限状态支持允许的玩家操作。数据表示改变不能产生额外能力；真实几何、连接或材料状态改变则可以改变结果。

### 9.1 分割

数量按实际相与空间分布分配，明确各自单位。均匀材料可按质量或体积比例近似；分层、表面污染和夹杂不能一律平均。不得按市场价值分配守恒物质量。

切割、拆解、研磨、化学分解分别更新。新增表面积和结构破坏可影响反应与响应，纯数据库分件不能凭空增加容量。

印记或连续关系按明确规则继承，主连续体可以是一种候选，但不是所有信息必须不可复制的通用公理。普通信息复制、载体分割和身份复制分别处理。

### 9.2 合并

同类守恒数量直接相加，容量和响应可饱和；超出容量的物质必须留存、溢出、析出、转移或产生定义过的失效，不得因饱和而删除。

混合不自动等于反应或均匀化。相位可能相消，结构和历史可能失配；这些变化不能消灭未被消耗的材料库存。

### 9.3 容器

容器具有壁面、开口、连接、内部有效空间及需要的分区。材料相之间可以分层、沉积、交换和反应；取样位置与倾倒方向需要与实际分区一致。

泄漏、污染、热传递、场屏蔽、压力承载和身份识别分别计算。打开盖子不自动清空内部库存，装箱不隐藏活体或危险内容物的真实状态。

### 9.4 库存与离线

背包、仓库、邮件、拍卖行和离线对象须有持久状态与运输／存放语义。高频表现可冻结，但与之后玩法有关的物质转化、泄漏、衰变与压力演化不能无条件暂停。

同一对象不得在客户端、区域交接和交易中同时计入多个库存。特定危险或高耦合物体可以要求实际存放设施，但限制需公开对应规则，不能依靠未说明的物品标签。

角色离线保护属于体验规则，需与仍存在于世界的材料库存区分；不得把下线变成保存反应物或复制载体的方法。

### 9.5 复制与模板

区分形状、工艺程序、材料状态、信息记录、历史印记和身份连续性。制造新载体需要真实原料与处理；复制工艺程序不等于免费复制产物。

普通记忆或信息记录不应一概被当成不可复制的身份关系。成对界膜、活体身份等若有特殊连续性要求，须单独登记。机械结构、化学组成相同不自动赋予这些关系。

### 9.6 玩家身体

身体与灵魂参与自然时，明确结构、动态状态、来源、损伤、恢复和观测方式。物理状态可以影响实际操作能力，但个人科技节点不作为外部材料反应的启用条件。

对基础运动的改变走受支持的载具、受力、约束或空间接口。避免无提示的长期伤害、无法反制的控制和账号级不可恢复惩罚；这些体验边界需与具体自然机制分层表达。

不默认把在线时长或被动消耗灵魂作为高级工业必需燃料。活体控制、可记录程序与自动化的替代范围应由具体机制说明。

### 9.7 跨区域搬运

对象携带其实际内容物、绑定组分、内部状态与已定义关系。游离物质是否随容器或空气团移动，由边界和流动决定；沉积能否带走，由稳定性和提取操作决定。

到达新环境后更新背景、边界交换和局部响应，不按区域名称直接授予或删除能力。跨区域过程需要保持物料、连续性和求解状态，不产生双重库存或重复外部供能。

### 9.8 气体、微量组分与场作用的补充测试

加热密闭混合物时保持气液固总账；蒸发、化学放气、泄压与吸附不能各自重复使用同一份库存。烟尘沉积、气体溶解和壁面污染均有明确去向。

验证大量处理低浓度材料能够累计真实回收量，不受小批次浮点截断、区域细分和显示阈值影响。

验证场源、执行器、介质和载具的组合反作用；测试闭合设备循环、源关闭、屏蔽、跨区传播及缓存更新。中性响应、诱导带荷和物种解离不能被合并成无条件“隔空提取元素”。

## 10. 元设计验收标准

保留有限表达、共同规则、多路径发现、实际能力门槛、跨系统用途和对象边界要求，并增加以下可执行验收项。这是验收清单，不是已通过的测试报告。

| 验收项 | 最低证明内容 |
| --- | --- |
| 本体分层 | 元素、物种、相、混合物、物体、场与关系分别表示；不可见性不取消账目。 |
| 共同机制 | 同一机制作用于多种材料，相同材料也能参与多种机制；非接触作用不是少数专用道具权限。 |
| 逆向初态 | 常见材料和地区差异能由实例规则支持，不是只有特殊科研材料才有内部状态。 |
| 化学闭合 | 输入、产物、排放、剩余物、反应竞争与相关能量义务明确，产物能够再次组合。 |
| 气相闭合 | 至少一条蒸发／反应、气体搬运、分离、回收或沉积链，及其密闭与泄漏对照。 |
| 跨源同本源 | 同一目标组分从易处理富矿、难处理材料与废物流取得后能交叉验证。 |
| 同组成异表现 | 至少一组材料通过结构或相差异表现不同，并可通过实验区分成分不足、污染和状态失配。 |
| 开放加工 | 中断、取样、换容器、替代设备与自动化复现均保留相同过程状态。 |
| 场与反作用 | 明确源、传播、响应、物质／场边界，以及功和动量的承担者。 |
| 观测可信度 | 仪器输出来自信号模型而非后台答案；量程、误差、采样扰动和统计规则可检查。 |
| 发现可达性 | 多个地区开局、启动设备、样品和工业数量路径明确；知识与物理许可分离。 |
| 稀缺可改变 | 至少一条技术显著扩展有效来源或替代天然成品，旧存量不因研究临时增加。 |
| 劳动可替代 | 技术减少某类重复劳动或无效搜索，而非只增加固定工序；知识扩散允许后来者采用成熟方案。 |
| 近似一致性 | 不同分辨率、在线／离线与区域切换的结果在声明精度内一致，微量账目不丢失。 |
| 组合无套利 | 分割、合并、回收、传送、充能、做功与储存循环不产生未声明源。 |
| 世界稳定性 | 常态气氛、材料与背景源存在足够稳定的初态；不是一开服就因未约束反应耗尽介质。 |
| 技术权衡 | 比较完整方案，允许旧工艺淘汰；不得靠隐藏等级和临时稀缺恢复旧耗时。 |
| GDD接口 | 至少连接经济、战争、身份、情报和科研中的两个模块，并明确社会干预不能覆写物理。 |

原型结果应记录误差、运行负载、失败样例和适用边界。静态图连通、元素配平或示例可运行，都不单独等于全局能量、实时性能或市场平衡通过。
