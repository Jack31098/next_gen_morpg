## 核心设计原则

深层科技不是解除约束，而是把旧约束替换成更复杂、更可研究、更可利用的新约束。

传统科技经常把数值从 `+37%` 推到 `+42%`，但这里的终局科技应该改变玩家对世界规则的理解。例如距离曾经意味着运输成本，瞬移技术出现后，距离的约束被锚点、同步、材料和干扰取代；食物曾经会自然腐败，时间场出现后，储存逻辑被场域大小、能耗、质量密度和设备稳定性取代。

科技越高，系统不应该越简单，而应该让摩擦转移到新的地方，并由此产生新的产业、战争、情报和科研空间。

发现由实际能力推动：开采、抵达、采样、加工或观测能力的提升，使原本无法进行的探索和实验成为可能。科技树表示这些能力的依赖关系，不决定自然规律是否开始生效。例如，特殊材料制成的钻地设备可让玩家首次取得深埋浮石；通过贸易取得同样样品的玩家，也能观察其悬浮现象。

## 深层物理的基本模型

每条深层物理规律都应该有一个可推导、可实验、可反制的结构：

```text
Effect = F(Resources, State, Environment, Geometry, History)
```

这意味着玩家最终发现的不是一句简单的系统说明，例如“世界允许瞬移”，而是一条更像自然规律的工程条件：

```text
当两个经过同源处理的物体保持某种共振状态，
并且空间曲率差低于阈值时，
可以发生非局域交换。
```

这类规律天然要求玩家做实验、建模、反证、产业化和反产业化。

## 约束类型

每条深层物理至少需要四类约束：

| 约束 | 作用 |
| --- | --- |
| 资源约束 | 防止能力无限使用，并制造新资源、新贸易和新争夺点。 |
| 状态约束 | 让处理流程、设备维护、同步、预充能等工程步骤有意义。 |
| 环境约束 | 让地理、战场、矿区、引力、污染、气候等环境条件影响科技应用。 |
| 反制约束 | 让对手仍能参与博弈，形成反科研、情报和防御体系。 |

约束不是单纯用来削弱能力的平衡补丁。约束本身就是隐藏空间的维度，玩家可能先发现能力，再不断发现能力边界，最后把边界变成新的工程方案。

## 技术路线权衡与深层参数

规律系统必须提供足够多可分别调节的参数，使不同技术路线在载重、速度、成本、基础设施、环境适应性和受干扰程度等方面形成权衡。没有一条路线应在所有主要场景都占优；这不要求各路线处处等强，也不阻止某地区或某次突破取得明显优势。

参数多并不自动产生平衡，需要比较各路线及其组合在主要场景中的完整建设与运行条件。后续深层技术也要纳入比较，不能让提高某一能力同时无条件消除全部代价。

某些表层参数可由更深层规律支配：早期实验只覆盖狭窄条件，玩家把参数当作常数；新设备、新材料或新地区带来的可复现偏差，使玩家发现隐藏依赖，并研究如何利用、控制或干扰它。例如浮石的单位承载系数可在常见条件下近似固定，在新的场域或材料状态下发生变化。

这种依赖从一开始就属于世界规则，不因玩家完成科技节点而临时加入。其后台表示可以是有限查表或分段函数。具体定义与验收要求见[元设计第 7.6 节](physics_meta_design.md#76-可调节的技术权衡与深层参数规律)。

## 示例：瞬移技术

瞬移如果没有限制，就只是传送按钮。它应该先表现为一组可研究的非局域交换现象，再逐渐产业化。

可能约束：

- 必须提前建立两个锚点。
- 锚点需要同源材料。
- 质量越大，成本非线性上升。
- 距离不是主要因素，但引力环境会干扰。
- 生物组织比无机物更难稳定。
- 传送会积累相位偏差。
- 连续使用会让锚点失配。
- 某些材料天然阻断传送。

早期应用不应该直接是士兵满地图闪现，而更可能是弹药、药品、零件等小质量物资补给。后勤革命先发生，人员传送后发生。

当生物稳定性被解决后，人员传送出现。敌方随即研究相位干扰场，战争也随之转向：

- 建锚点。
- 保护锚点。
- 干扰敌方锚点。
- 争夺相位材料。

此时瞬移不再是一个技能，而是新的战争基础设施。

## 示例：时间减速

时间场也应该从小规模、非战斗用途开始成长。可以用这样的底层关系表达：

```text
dt_world / dt_local = f(FieldDensity, Volume, Mass)
```

如果区域越大能耗指数上涨，那么最早的实用设备可能不是战斗领域，而是几十厘米的小型时间减速容器。

早期用途：

- 延缓药品腐坏。
- 保存稀有生物样本。
- 延缓伤员恶化。
- 储存高反应性材料。

中期用途：

- 2 米级精密加工舱。
- 极端化学反应控制。
- 工业流程加速或减速。

后期用途：

- 20 米级战术时间场。
- 火控与拦截系统扰动。
- 战场局部时序工程。

限制条件本身也要成为科研对象。玩家可能早期只知道“时间场不能做太大”，之后发现关键并不是尺寸，而是场内总质量。于是新工程方案出现：先把区域抽真空，再启动时间场，性能突然提升。再往后，某种材料能降低等效场质量，材料市场也被重新塑形。

## 深层物理组合

深层物理之间应该可以组合，但组合条件需要苛刻。组合不是简单的科技合成，而是不同规律在特定条件下出现新的现象。

例如：

```text
Teleportation + TimeField -> 延迟传送
```

物体进入系统后不是立即出来，而是在不同时间流速区域缓存。由此可以出现战略物资冻结仓库、时滞传送补给、延迟投送等系统。

又例如：

```text
MatterReplication + InformationPhysics -> 根据高精度状态描述重构物体
```

如果再叠加生命科技，可能出现生物复制。这会撬动经济、身份、伦理和死亡等底层社会结构。

重要的是，玩家即使发现了 `Law A` 和 `Law B`，也不意味着组合空间被耗尽。也许半年后才发现：

```text
Law A + Law B + Condition C -> 更深层行为
```

这种层级组合能避免隐藏规律被社区 wiki 一次性穷尽。

## 科研发现作为服务器叙事

科研发现本身应该变成服务器级叙事内容。

当某个城邦突然使用一种诡异炮兵战术，例如炮弹飞行途中出现短暂异常减速，导致敌方拦截系统算错，其他玩家不应该只理解为“他们科技等级高 3 级”。更有趣的问题是：

- 他们发现了什么自然规律？
- 这是新推进剂、导航系统、时序异常，还是某种隐藏场效应？
- 我们能不能从战场残骸里逆向？
- 哪些材料会因此涨价？
- 这是不是还有下一层？

一个发现可以自动制造：

- 科研内容。
- 战争内容。
- 情报内容。
- 商业投机。
- 政治博弈。
- 社区讨论。

这会把科技系统变成集体悬疑，而不是菜单里的升级列表。

## 不公开传统科技树

深层规律最好不要公开成传统科技树。不要让玩家打开菜单就看到：

```text
Tier 8: 局部时间场
Tier 9: 空间折叠
Tier 10: 物质复制
```

玩家应该只看到文明已经理解的知识边界：

```text
已确认规律
├─ 热诱导相变
├─ 共振耦合
│  ├─ 远距同步：已确认
│  └─ 非局域响应：理论争议
└─ 时序异常
   └─ 原因未知
```

未发现的内容不应该显示为“未解锁科技”，而应该表现为异常现象、未验证假说、无法解释的数据和理论争议。

“未解锁科技”意味着系统知道答案，玩家还没肝到。

“异常现象”意味着世界有秘密。

## 多文明知识差异

不同城邦或文明应该掌握同一宇宙的不同局部真相。

例如 A 城邦发现某种材料会产生时间异常，B 城邦从信息系统里发现高频同步误差与地理位置相关。两边实际上观察的是同一个深层规律 `SpacetimeField`，但在统一理论出现之前，没有人知道它们是一件事。

当玩家把两组论文或战场数据联系起来，提出“相位场统一理论”，这应该成为服务器级事件，并展开新的研究空间。

官方不应该确认“这个世界是否已经被研究完”。不显示“共 73 项终极规律”，也不显示“当前科技完成度 67%”。玩家面对的是世界，而不是内容清单。

## 文明科技路径

科技树不应该是角色创建界面的预设阵营加成，而应该是文明历史走出来的路径。

文明 A 先发现非局域共振：

```text
远距同步 -> 超低延迟通信 -> 无线能量传输 -> 锚点技术 -> 短距物质交换 -> 瞬移网络
```

文明 B 先发现局部时间梯度：

```text
高精度计时 -> 延缓腐败 -> 工业过程减速/加速 -> 时间缓存 -> 战术时间场 -> 极端时序工程
```

文明 C 先在材料方向挖深：

```text
结构记忆 -> 可编程材料 -> 自修复装甲 -> 形态重构 -> 物质状态写入
```

几十周后，这些文明会像不同的科幻文明。但差异不是策划预设的，而是地理、经济压力、战争和玩家兴趣共同塑造的。

```text
Environment + Problems + PlayerInterest -> ResearchPath
```

## 认知锁定与路径依赖

科技路径应该产生认知锁定和基础设施路径依赖，但不能绝对锁死。

如果 A 文明已经围绕瞬移路线建立了：

- 相位晶体矿。
- 锚点工厂。
- 同步网络。
- 专业科研院。
- 传送物流标准。

那么他们当然仍可以研究时间科技，但转型代价会很高。继续在既有方向上深挖，边际收益更高。这类似现实中的技术路径依赖。

这不是“你选了蓝色科技树，所以不能点红色”，而是“你当然可以转型，但整个国家已经围绕另一套技术建起来了”。

## 同一规律的不同应用树

即使两个文明发现同一条深层规律，也可能产生不同应用方向。

例如双方都发现时间场：

```text
文明 A: 时间场 -> 火控 -> 防御 -> 战术领域
文明 B: 时间场 -> 精密制造 -> 药品保存 -> 生物医学
```

科技树至少有两层分叉：

```text
FundamentalLaw -> ApplicationPath
```

发现什么规律决定第一层。社会拿它解决什么问题决定第二层。这样文明会拥有真正的性格。

## 战争与技术融合

战争不只是抢土地和 GDP，也可能改变世界的知识图谱。

例如：

```text
Teleportation_A + TemporalPhysics_B -> NewBranch
```

A 文明拥有瞬移物流，B 文明拥有时间场武器。A 攻占 B 的研究城后得到部分时间技术，几年后出现时滞传送系统。这不是任何文明原本拥有的分支，而是两条独立技术史碰撞后的新分支。

这会让情报职业和科研成果保护变得极其重要。偷一份论文、抢一台原型机、俘获一名工程 NPC，可能比占领普通矿区更有价值。

## 玩家 UI 表达

尽量避免在玩家 UI 中使用“科技树”这个词。幕后当然可以是图结构，但玩家看到的应该是文明知识图谱。

知识图谱中，已发现部分亮起，边缘显示：

- 异常。
- 假说。
- 未验证关系。
- 理论争议。
- 实验失败记录。

更外层保持黑暗。

不同文明打开知识图谱时，看到的是不同形状的已知世界。这种差异比单纯军事力量差异更刺激，因为它意味着：“他们知道一些我们不知道的东西。”

## 后续可设计模块

- 科研实验系统：如何让玩家通过材料、环境、设备状态和数据记录触发异常。
- 文明知识图谱：玩家可见 UI、幕后图结构、假说和验证机制。
- 情报与逆向工程：论文、原型机、残骸、工程 NPC 和战场日志的价值。
- 深层规律数据结构：`Law`、`Condition`、`Constraint`、`Application`、`Countermeasure` 的建模。
- 科技泄露与融合：战争、贸易、间谍、迁徙如何改变文明路径。
- 服务器级发现事件：如何广播发现而不破坏神秘感。
